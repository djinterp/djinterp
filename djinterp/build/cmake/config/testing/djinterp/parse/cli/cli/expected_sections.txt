# How many sections the command-line kit's suites run in each build, in the
# default configuration (testing mode, every knob at its default): the C
# suites at each C level, the allocation sweep at the C floor (`-sweep`),
# the C++ suite at each C++ level, and the C++ suite without exceptions
# (`-noexc`) at the lowest and the highest.
#   A suite is a table of sections, and a section is the unit a configuration
# knob removes. A section that silently stopped being compiled would
# otherwise read as a smaller pass; these are the counts that make it a
# failure instead.
#   Both builds read this file -- CMakeLists.txt and run_cli_tests.sh, beside
# it -- so there is one place to change when a section is added. A line is
# `<build> <sections>`; anything else is a comment.
#   A build under a configuration knob runs fewer sections, by design, and is
# not held to these counts: DJINTERP_CLI_EXPECT_COUNTS in CMakeLists.txt.
#
