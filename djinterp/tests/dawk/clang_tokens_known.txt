# clang_tokens_known.txt -- the files where parse's lexer and Clang's raw
# lexer disagree, each with where and why: the punch list of
# tests/dawk/clang_tokens.sh and the CTest suite djinterp_dawk_clang_tokens.
# A file listed here may disagree; a file that agrees is taken off. Each line
# is the path, a tab, and where the first disagreement stands and what it is.
# Both kinds are the lexer's, in c/modules/parse:
#   - C23's :: read as two colons: C23 makes :: a punctuator, for attribute
#     prefixes ([[gnu::...]]), and the C tables hold it as C++'s alone;
#   - a line splice read into the token after it: after a comment, a
#     backslash-newline before the next token is read as that token's first
#     characters, so the token starts a line early, at the backslash.
